# Disaster Recovery Readiness

This project validates that a recovery exercise has accountable owners, concrete evidence, and observable pass conditions for restoration, decision-making, communications, and insurance readiness.

Run from the repository root:

```bash
python disaster-recovery-readiness/src/validate_recovery.py
```

The structural validator checks exercise metadata. The readiness gate separately requires an observed evidence reference and PASS status for restoration, decision-making, communications, and insurance readiness.
