# Layered Defense Plan

This project validates a preventive defense matrix and publishes a prioritized roadmap.

## Run

From the project directory, run:

```bash
python3 src/validate_matrix.py
```

The report checks that each preventive control has an owner and verification evidence,
prioritizes controls protecting the critical workload, sequences the roadmap, preserves
an insider-risk workstream, and routes uncovered visibility and incident-handling needs
to detective or response capabilities.
